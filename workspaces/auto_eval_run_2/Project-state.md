# Project State: AI-Powered Guest Sentiment Dashboard

## Problem Context

Hotel staff spend hours manually reading and responding to guest reviews across multiple platforms. There is no centralized way to visualize trends or identify specific recurring operational failures (e.g., "noisy AC in room 302").

## Business Goal

Create a centralized dashboard that aggregates reviews from Google, TripAdvisor, and Yelp, uses Natural Language Processing (NLP) to categorize sentiment and specific themes, and provides a "Top 3 Action Items" list for General Managers daily.

## Key Constraints

- Must comply with platform Terms of Service (no scraping; use official APIs or authorized partners).
- Must provide multi-language support (English, Spanish, French).
- Dashboard must be mobile-friendly.
