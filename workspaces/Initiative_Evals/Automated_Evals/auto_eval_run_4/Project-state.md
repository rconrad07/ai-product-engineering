# Project State: Hyper-Personalized Upsell Engine

## Problem Context

Currently, upselling is manual or uses simple rule-based emails (e.g., "everyone gets a 10% breakfast coupon"). This results in low conversion rates (under 2%) and missed high-value opportunities like room upgrades or spa bookings.

## Business Goal

Develop an AI-driven upsell engine that integrates with the CRM (Customer Relationship Management) and PMS. The engine should use past behavior, booking data, and real-time availability to offer personalized upgrades via SMS or push notification before and during the stay.

## Key Constraints

- Must comply with GDPR and CCPA (data privacy).
- Must integrate with existing email/SMS marketing platforms (e.g., Salesforce Marketing Cloud).
- Must have a "control group" for A/B testing conversion lift.
