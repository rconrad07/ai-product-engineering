# Project State: Contactless Digital Key Integration

## Problem Context

Front desk queues during peak check-in times (3 PM - 6 PM) lead to low guest satisfaction scores. Manual ID verification and physical key card issuance are bottlenecks.

## Business Goal

Implement a fully contactless check-in flow via the hotel mobile app. This includes mobile ID upload, credit card pre-authorization, and the issuance of a Bluetooth/NFC digital key to the guest's device.

## Key Constraints

- Must integrate with major lock hardware vendors (Assa Abloy, Dormakaba).
- Must meet strict security standards for digital key encryption and transmission.
- Must include a physical fallback (kiosk or desk) if the guest's phone battery is dead.
