# Product Orchestrator Decision Tree

## Step 1: Identify Product Task Type
Possible values:
- New Feature Definition
- Iteration / Enhancement
- Discovery Summary
- Documentation Update

## Step 2: Select Agents
- Business Analyst: always required
- Solutions Architect: required if technical constraints exist
- Market Analyst: required if competitive context is requested

## Step 3: Generate Draft Artifacts
- Populate product_state.md
- Generate template-aligned drafts

## Step 4: Human Product Approval
- Approval required before:
  - Jira ticket creation
  - Confluence publishing

## Step 5: Post-Approval Actions
- Export approved content
- Log final outcome
